# КОГО ТЫ ОСТАВИЛ? / WHO DID YOU LEAVE?

Психологический хоррор от первого лица на Godot 4.7 (GDScript).
Текущее состояние: **вертикальный прототип** — одна цельная последовательность
на 10–15 минут с тремя концовками.

## Как запустить

1. Откройте `Godot_v4.7.2-stable_mono_win64.exe` → **Import** → выберите `project.godot` из этой папки.
2. При первом открытии редактор импортирует текстуры и звуки (несколько секунд).
3. Нажмите **F5** (Run Project). Стартует главное меню.

Проект написан на GDScript, .NET/C# для него не нужен (Mono-сборка Godot его просто открывает).

## Что сделано

- **Игрок**: ускорение/торможение без скольжения, бег, присед с проверкой потолка, ограничение наклона камеры, мягкое покачивание (отключается), шаги (на бетоне — другой звук, при приседе тише), фонарь с небольшим запаздыванием, заморозка камеры в меню/документах.
- **Взаимодействия** через общий класс `Interactable` (Area3D + луч от камеры): двери (закрыта/открыта/заперта, вращение на петле, открывается от игрока), ключи, записки, осмотр предметов с вращением, выключатели, рубильник, радио, телефон, домофон, сюжетные объекты.
- **Уровень «Дом»**: стартовая комната (кв. 10), коридор, кв. 11 (A), кв. 12 (B), кв. 14 (C), щитовая, лестничная клетка с решёткой (закрытый проход) и скрытая кв. 13 на полуэтаже.
- **Сюжет**: домофон с выбором ответа, стук в трубе после дневника соседки (можно ответить или уйти), радио называет найденное имя, телефон звонит (можно ответить или проигнорировать), квартира A меняется в отсутствие игрока, на фотографии появляется новая деталь, обычная труба в щитовой, фигура на лестнице исчезает в луче фонаря, голос за дверью 13 повторяет прочитанную фразу, финальное «Объяснение».
- **Три концовки** с вариантами; условия скрыты и зависят от сочетания найденного и сделанного.
- **Сохранение** (JSON, атомарная запись, версия формата, обработка битых файлов), автосохранение на контрольных точках, «Продолжить» в меню.
- **Интерфейс**: главное меню с 3D-фоном, пауза, настройки (громкость 5 шин, мышь, инверсия, субтитры, покачивание, VHS, полный экран), журнал, субтитры, экран концовки.
- **Звук**: шины Master / Ambience / SFX / Dialogue / Music, 3D-источники, слоты звуков с заменяемыми файлами.
- **VHS-постобработка** (3 уровня, включая «выкл.»).

## Структура

```
scenes/   menus, levels, player, characters, interactables, props, ui
scripts/  core (состояние, настройки, переходы), player, interaction, narrative,
          audio, save, ui, lighting, characters
data/     locale (строки UI), story (документы, осмотр), dialogue (сообщения), endings
assets/   textures, audio, fonts, characters (слоты моделей)
tools/    генераторы ассетов/сцен и автотесты
```

Вся сценарная логика — в `scripts/narrative/house_director.gd`.
Тексты — только в `data/*.ru.json` (для английского добавьте `*.en.json`).

## Инструменты

```
# Пересобрать 3D-сцены (материалы, пропсы, двери, игрок, уровень, фон меню)
godot --headless --path . --script res://tools/build_scenes.gd
# Автотест: проходит игру и проверяет 100+ условий
godot --headless --path . --script res://tools/run_tests.gd
# Перегенерировать процедурные текстуры / звуки (нужен Python + numpy, scipy, Pillow)
python tools/gen_textures.py .
python tools/gen_audio.py .
```

⚠ `build_scenes.gd` перезаписывает сгенерированные сцены. Если правите уровень в редакторе —
либо больше не запускайте генератор, либо вносите изменения в сам генератор.

Подробно о моделях и звуках, которые нужно заменить: `docs/ASSETS.md`.

# Ассеты: что временное и что нужно заменить

Все текстуры и звуки сейчас **процедурные** (созданы скриптами `tools/gen_textures.py`
и `tools/gen_audio.py`), чужих ассетов в проекте нет. Шрифты — DejaVu (свободная лицензия,
см. `assets/fonts/DejaVu-LICENSE.txt`).

## Модели (GLB/glTF из Blender)

Слоты уже есть в сценах (`scripts/characters/model_slot.gd`). Положите файл по пути —
модель подхватится автоматически, заглушка спрячется. Пока файла нет — видна заглушка.

| Путь | Что | Требования |
|---|---|---|
| `assets/characters/player/fp_arms.glb` | руки и предплечья для вида от первого лица | крепится к камере (`Player/Head/Camera/HandsSlot`), смотрит в −Z, масштаб 1 ед. = 1 м |
| `assets/characters/player/player_body.glb` | полное тело героя | только для отражений/теней/постановочных сцен, по умолчанию скрыто |
| `assets/characters/figure/figure.glb` | загадочная фигура | человек, рост ~1.85 м, тёмная одежда, без «монстровых» черт; начало координат — между ступней |
| `assets/characters/residents/resident_base.glb` | базовый жилец (`scenes/characters/Resident.tscn`) | общий скелет для всех жильцов |

**Анимации** (в `AnimationPlayer` внутри GLB, имена как есть):
`idle`, `walk`, `turn`, `reach`, `startled`, `talk`. Используйте один скелет для всех жильцов,
чтобы анимации переиспользовались. Экспорт из Blender: glTF 2.0 (.glb), +Y Up, применить масштаб.

## Звуки

Имена слотов → файлы — в `scripts/audio/audio_manager.gd` (`SLOTS`). Чтобы заменить звук,
положите файл с тем же именем (или поменяйте путь в `SLOTS`). Поддерживаются `.wav` и `.ogg`.
Зацикленные слоты перечислены в `LOOPING`.

**Озвучка** ещё не записана: пути к голосовым файлам указаны прямо в
`data/dialogue/messages.ru.json` (поле `voice`, например
`res://assets/audio/voice/intercom_01_a.ogg`). Пока файла нет, реплика показывается
субтитром даже при выключенных субтитрах.

## Текстуры

`assets/textures/*.png` — тайлящиеся заглушки (обои, краска, линолеум, паркет, бетон,
дерево, металл, ткань, бумага) и сюжетные изображения (фотографии, календарь).
Материалы — `resources/materials/*.tres` (триплanarное наложение, поэтому UV на
геометрии не нужны). Для настоящих материалов добавьте карты normal/roughness в те же `.tres`.
